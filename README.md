# EM27 Metadata Storage

Store the metadata for your EM27/SUN network in [`em27_metadata.toml`](em27_metadata.toml). Replace the example values with your locations, sensors, campaigns, and events while keeping the same structure.

The included GitHub Actions workflow validates every push and pull request against the schema bundled with EM27 Retrieval Pipeline. The schema is documented at [tum-esm.github.io/em27-retrieval-pipeline/guides/em27-metadata](https://tum-esm.github.io/em27-retrieval-pipeline/guides/em27-metadata).
